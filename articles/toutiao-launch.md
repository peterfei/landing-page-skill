# 从需求到上线只要1个对话：我开源了一个全链路落地页生成工具

**导语：做了8年前端，我第一次见到能同时搞定文案、设计、代码三件事情的AI工具。**

---

## 01｜一个让人崩溃的现实

上周，一个朋友找我帮忙做落地页。

需求很简单：一个编程训练营的招生页面。但你知道完成这件事需要多少环节吗？

- 先找产品经理对齐文案结构
- 再跟设计师确认视觉风格
- 最后前端写代码、调响应式、做适配

**3个人，5轮沟通，2周时间。**

而这还只是"做完"，不是"做好"。

更扎心的是，上线后转化率不到2%——因为文案没打中痛点、CTA按钮文案太模糊、缺少社会证明……

这些错误，每一个都是教科书上写烂的常识。但人忙起来，就是会忘。

我开始想：**能不能让AI把这套流程一次性做完，而且做对？**

---

## 02｜我做了什么

经过1周多的打磨，我做了一个叫 **Landing Page Skill** 的开源项目。

它的核心理念就一句话：

> **文案策略 + 视觉设计 + 代码实现，三位一体，一次对话，直接上线。**

不是那种"AI帮你写代码"的半成品。是整个工作流：

**第1步：你说需求**

> "帮我设计一个落地页，面向应届毕业生，推广编程训练营，风格要大胆、有冲击力。"

**第2步：AI自动走完5个阶段**

| 阶段 | AI做什么 | 传统方式耗时 |
|------|---------|-------------|
| 需求采集 | 确认受众、目标、技术栈 | 2天沟通 |
| 策略规划 | 选行业模板、定美学风格、规划文案结构 | 3天 |
| 设计系统 | 生成配色、字体、动效、布局Token | 2天 |
| 代码生成 | 输出Next.js + Tailwind生产级组件 | 5天 |
| 质量验证 | 转化检查 + 反模式检测 + 技术审计 | 半天 |

**第3步：你拿到可直接运行的代码**

不是骨架。是完整可跑的Next.js项目，包含：

- Hero区域 + 社会证明 + 痛点 + 卖点 + 学员评价 + FAQ + CTA + 页脚
- 响应式设计（手机、平板、桌面）
- 设计Token（颜色、字体、间距）统一管理
- 经过反模式检测，确保没有常见错误

**整个对话，10分钟。**

除此之外，它还覆盖了落地页开发所需的全部能力模块：

| 模块 | 说明 |
|------|------|
| **5 阶段协议** | 需求采集 → 策略规划 → 设计系统 → 代码生成 → 质量验证 |
| **11 元素转化框架** | Hero、社会证明、Features、Benefits、How It Works、Testimonials、Pricing、FAQ、CTA、稀缺性、Footer |
| **7 段式文案框架** | Hero → 痛点 → 解决方案 → 利益 → 证据 → 异议处理 → CTA |
| **6 种美学风格** | 极简 / 大胆 / 复古 / 有机 / 编辑 / 粗野 |

| **技术栈适配器** | Next.js 14/15 + Tailwind CSS（App Router） |

## 03｜为什么它能"一次性做对"

传统AI写代码的问题在于：**只负责生成，不负责把关。**

Landing Page Skill内置了一套**反模式检测器**，在生成阶段就拦住5类常见错误：

1. **字体泛滥** — 一个页面用了4种以上字体 → 统一规范
2. **模板配色** — 直接用Tailwind默认蓝色 → 按品牌风格重配
3. **CTA模糊** — "点击这里" → 改成"预约免费试听"
4. **缺少社会证明** — 没有数据、没有评价 → 自动补充
5. **Hero标题无力** — 只写产品名 → 改成"90天拿到Offer"

这些不是后验检查。是**生成过程中实时拦截**。

就像有一个资深前端 + 产品经理 + 设计师，坐在AI旁边审稿子。

这是我昨天刚跑的测试案例：

**需求：** 零基础转行编程训练营落地页
**受众：** 应届毕业生，找不到工作
**目标：** 预约免费试听
**风格：** 大胆（黑红配色，强视觉冲击）

**AI输出结果：**

- 9个Section完整落地页

- 5个FAQ预置异议处理
- Next.js 15 + Tailwind CSS，直接npm run dev运行

**从我说需求到页面跑起来，30分钟。**

## 05｜谁适合用

如果你符合以下任意一条，这个工具能帮到你：

- **独立开发者** — 不想花时间在CSS调间距上
- **创业团队** — 没有专职设计师，但需要高转化落地页
- **AI Agent用户** — 想让Claude Code/Cursor/Trae生成更专业的页面
- **前端工程师** — 厌倦重复写同样的Section结构

**不适用于：** 需要复杂后端交互、多页网站、非Web平台。

## 06｜怎么用

一行命令安装：

```bash
npx skills add peterfei/landing-page-skill
```

支持Claude Code、Codex CLI、Cursor、Trae等50+运行时。

激活词也很简单：

> "帮我设计一个落地页"

然后AI会自动走5阶段协议，你只需回答几个确认问题。
