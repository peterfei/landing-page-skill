# 转化框架：DESIGNNAS 11 元素 + 7 段式文案

## DESIGNNAS 11 元素定义

| 元素 | 目的 | 典型位置 | 内容指南 |
|------|------|---------|---------|
| **Hero** | 3 秒内传递核心价值主张，吸引继续阅读 | 页面首屏 | 标题用 "结果+受众+机制" 公式，副标题补充价值，CTA 按钮突出 |
| **Social Proof** | 建立信任，降低首次访问者的心理防线 | Hero 下方或紧邻 | 客户 Logo 墙、用户数量、评分星级、权威媒体提及 |
| **Features** | 展示产品/服务功能点，支撑价值主张 | 页面前 1/3 | 3-4 个核心功能，每个配图标+标题+一句话描述，避免功能罗列 |
| **Benefits** | 翻译功能为用户获得的实际利益 | Features 之后 | 用 "你能获得什么" 而非 "我们有什么" 的视角，配情感化描述 |
| **How It Works** | 降低使用门槛，展示获取价值的简单路径 | 页面中部 | 3-4 步流程，每步配序号+标题+简短说明，可视化流程线 |
| **Testimonials** | 用真实用户声音增强可信度 | 页面中后部 | 真人头像+姓名+职位+具体成果数据，避免匿名评价 |
| **Pricing** | 消除价格疑虑，推动决策 | 页面中后部 | 3 档定价（推荐中间档高亮），清晰对比功能差异 |
| **FAQ** | 主动回答常见异议，减少流失 | Pricing 之后 | 5-7 个高频问题，问题用用户口吻，答案简洁有力 |
| **CTA** | 明确引导用户完成转化动作 | 多处分布（Hero/中段/底部） | 统一 "动词+利益" 格式，按钮视觉层级最高 |
| **Scarcity/Urgency** | 创造行动动机，减少犹豫 | 紧邻 CTA | 限时优惠、剩余名额、倒计时（真实可信，避免虚假紧迫感） |
| **Footer** | 提供辅助信息和法律合规 | 页面底部 | 版权、隐私政策、联系方式、社交媒体链接 |

## 7 段式文案框架

```
Hero → Problem → Solution → Benefits → Proof → Objection Handling → CTA
```

| 段落 | 目的 | 对应 DESIGNNAS 元素 |
|------|------|-------------------|
| **Hero** | 抓住注意力，承诺结果 | Hero |
| **Problem** | 共鸣用户痛点，建立相关性 | Hero 副标题 / 独立 Problem Section |
| **Solution** | 展示产品如何解决痛点 | Features + How It Works |
| **Benefits** | 强调用户获得的实际价值 | Benefits |
| **Proof** | 用证据支撑 claims | Social Proof + Testimonials |
| **Objection Handling** | 消除购买/注册前的顾虑 | FAQ + Guarantee |
| **CTA** | 明确下一步行动 | CTA (Hero + 中段 + 底部) |

## 文案段落到元素映射表

```
Hero 段落        → Hero 元素
Problem 段落     → Hero(副标题) 或独立 Problem Section
Solution 段落    → Features + How It Works 元素
Benefits 段落    → Benefits 元素
Proof 段落       → Social Proof + Testimonials 元素
Objection 段落   → FAQ + Guarantee 元素
CTA 段落         → CTA 元素（Hero/中段/底部三处）
```

## 元素覆盖率检查清单（Phase 5 使用）

- [ ] Hero：核心价值主张 + CTA
- [ ] Social Proof：信任信号
- [ ] Features：功能展示
- [ ] Benefits：利益转化
- [ ] How It Works：使用路径
- [ ] Testimonials：用户证言
- [ ] Pricing：价格信息（如适用）
- [ ] FAQ：异议处理
- [ ] CTA：转化引导（至少 2 处）
- [ ] Scarcity：紧迫感（如适用）
- [ ] Footer：辅助信息

**通过标准**：至少覆盖 7 个核心元素（Hero、CTA 为必须，其余选填但建议覆盖）。
