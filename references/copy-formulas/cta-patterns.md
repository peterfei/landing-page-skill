# CTA 模式库

## 核心格式

所有 CTA 文本必须遵循：

```
CTA = 动词 + 利益
```

- **动词**：明确、有力的动作指令（获取、开始、加入、解锁、预约）
- **利益**：用户完成动作后获得的具体价值

## 8 个 CTA 模式

### 1. 免费试用型（注册/试用转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "开始 14 天免费试用" |
| 动词+利益+无风险 | "免费试用，无需信用卡" |
| 动词+利益+时间 | "立即注册，5 分钟上手" |

### 2. 获取资源型（线索收集转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "获取免费方案报价" |
| 动词+利益+稀缺 | "下载 checklist（仅限前 100 名）" |
| 动词+利益+即时 | "立即获取 PDF 指南" |

### 3. 购买型（电商转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "立即购买，享 30% 折扣" |
| 动词+利益+保障 | "加入购物车，7 天无理由退换" |
| 动词+利益+稀缺 | "抢购限时优惠，仅剩 23 件" |

### 4. 预约型（服务咨询转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "预约免费咨询，获取定制方案" |
| 动词+利益+时间 | "预约 15 分钟演示，本周可排" |
| 动词+利益+零成本 | "免费预约，无任何附加条件" |

### 5. 下载型（App/软件转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "下载 App，随时随地管理" |
| 动词+利益+平台 | "下载 iOS 版，体验完整功能" |
| 动词+利益+奖励 | "首次下载送 7 天高级会员" |

### 6. 加入型（社区/会员转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "加入社区，获取独家资源" |
| 动词+利益+数字 | "加入 5000+ 创作者的圈子" |
| 动词+利益+即时 | "立即加入，解锁全部课程" |

### 7. 观看型（演示/教育转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "观看 3 分钟演示，了解全部功能" |
| 动词+利益+时间 | "观看案例视频，5 分钟看懂价值" |
| 动词+利益+结果 | "看客户如何 3 倍提升转化" |

### 8. 比较型（决策辅助转化目标）

| 模式 | 示例 |
|------|------|
| 动词+利益 | "对比方案，找到最适合你的" |
| 动词+利益+即时 | "立即对比，3 秒出结果" |
| 动词+利益+免费 | "免费获取个性化推荐" |

## CTA 质量检查清单

- [ ] CTA 文本是否包含明确的动词？
- [ ] CTA 文本是否包含用户获得的利益？
- [ ] CTA 是否避免了 Submit / Learn More / Click Here 等模糊表达？
- [ ] CTA 按钮是否在视觉上最突出（对比度最高）？
- [ ] 页面是否包含至少 2 个 CTA（首屏 + 底部）？
- [ ] 次要 CTA 是否与主 CTA 有视觉层级区分？

## 常见错误

| 错误 | 修正 |
|------|------|
| "Submit" | "获取免费报价" |
| "Learn More" | "查看如何节省 30% 成本" |
| "Click Here" | "立即下载完整指南" |
| "Sign Up" | "注册并开始 14 天免费试用" |
| "Get Started" | "5 分钟搭建你的第一个页面" |
| "Buy Now" | "立即购买，享首单 8 折" |
