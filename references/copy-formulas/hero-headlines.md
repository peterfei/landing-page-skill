# Hero 标题公式库

## 核心公式

```
Hero 标题 = 结果 + 受众 + 机制
```

- **结果**：用户能获得什么具体、可量化的成果
- **受众**：目标用户是谁（越具体越好）
- **机制**：通过什么方式/产品实现（可选，但建议包含）

## 公式变体

### 变体 1：结果优先型（最常用）

```
[具体结果]，[目标受众] 的 [解决方案]
```

- "3 倍提升销售线索，B2B 团队的智能获客工具"
- "将设计交付时间缩短 50%，独立设计师的自动化工作流"
- "每月节省 20 小时，电商卖家的库存管理系统"

### 变体 2：痛点共鸣型

```
[痛点]？[机制] 帮你 [结果]
```

- "客户流失严重？AI 预警系统帮你提前 30 天识别风险"
- "广告费烧太快？智能投放助手帮你降低 40% CPA"
- "团队协作混乱？一体化看板让项目进度一目了然"

### 变体 3：数字冲击型

```
[数字] [受众] 已用 [机制] 实现 [结果]
```

- "10,000+ 自由职业者已用此工具实现收入翻倍"
- "500+ 初创团队通过我们的方法在 3 个月内获得首轮融资"
- "98% 的用户在 7 天内看到明显的效率提升"

### 变体 4：对比反差型

```
告别 [旧方式]，用 [新方式] 实现 [结果]
```

- "告别手动报表，用自动化仪表盘实时掌握业务全貌"
- "告别反复修改，用 AI 辅助一次过稿"
- "告别信息孤岛，用统一平台连接所有工作流"

### 变体 5：时间紧迫型

```
[时间范围] 内 [结果]，即使你没有 [通常需要的条件]
```

- "7 天内搭建专业落地页，即使你不会写代码"
- "30 分钟学会数据分析，即使你不懂统计学"
- "1 周内上线电商店铺，即使没有技术团队"

## 标题质量检查清单

- [ ] 标题是否包含具体结果（而非空泛描述）？
- [ ] 标题是否明确或暗示了目标受众？
- [ ] 标题是否避免了 "Welcome to / We are / Introducing" 等无力开头？
- [ ] 标题是否在 15 个汉字以内可读完（或英文 10 个单词以内）？
- [ ] 标题是否可以在 3 秒内传达核心价值？

## 常见错误

| 错误类型 | 示例 | 修正 |
|---------|------|------|
| 纯品牌介绍 | "ABC科技 - 领先的智能平台" | "让客服团队效率提升 3 倍的 AI 助手" |
| 纯功能罗列 | "集 CRM、邮件、分析于一体" | "用一个工具替代 3 个订阅，每月省 $200" |
| 空泛承诺 | "提升你的业务" | "帮助 SaaS 团队在 90 天内将 MRR 提升 25%" |
| 技术术语堆砌 | "基于 LLM 的 RAG 知识库解决方案" | "让客服 3 秒找到答案，不再反复转接" |
