# 电商产品页模板

## 适用场景

- 单品电商落地页（DTC 品牌）
- 众筹产品页面
- 高端消费品（珠宝、手表、设计师家具）
- 健康/美容单品

## Section 结构

```
Hero → Social Proof → Problem → Product Features → Benefits → How It Works → Testimonials → Guarantee → CTA
```

---

## 1. Hero Section

**内容指南**：
- 标题：产品核心卖点（"睡眠革命：让你每晚深睡 8 小时"）
- 副标题：一句话价值主张 + 目标人群
- CTA：主按钮 "立即购买" / "加入购物车" + 价格信息
- 视觉：产品高清大图或 lifestyle 场景图

**设计要点**：
- 产品图占据 50%+ 视觉空间
- 使用 lifestyle 场景而非纯白底产品图
- 价格信息清晰可见（如有限时优惠，突出原价/折扣价对比）
- 可添加信任徽章（"免费配送"、"30 天退换"）

---

## 2. Social Proof Section

**内容指南**：
- 星级评分（"4.8/5 来自 2,300+ 评价"）
- 用户生成内容（UGC）缩略图网格
- 权威背书（"被 Vogue 推荐"、"获得红点设计奖"）
- 销量数据（"已售 50,000+ 件"）

**设计要点**：
- 评分用大字号 + 星星图标
- UGC 图片真实、多样
- 紧邻 Hero，建立即时购买信心

---

## 3. Problem Section

**内容指南**：
- 标题：用户当前面临的痛点（"你的护肤品真的被吸收了吗？"）
- 3 个痛点，每个配简短描述
- 痛点要与产品解决方案直接对应

**设计要点**：
- 使用对比图（Before/After 或 旧方式 vs 新方式）
- 痛点用图标 + 文字展示
- 营造 "你值得更好的" 情感共鸣

---

## 4. Product Features Section

**内容指南**：
- 标题："为什么它与众不同"
- 4-6 个产品特性，每个配高清特写图 + 标题 + 描述
- 聚焦材质、工艺、技术创新

**设计要点**：
- 大图配文字的非对称布局
- 特性图使用微距/细节特写
- 交替左右排版（Feature 1 左图右文，Feature 2 右图左文）
- 使用标注线（Callout lines）指向产品细节

---

## 5. Benefits Section

**内容指南**：
- 标题："它能为你带来什么"
- 3-4 个核心利益，每个配图标 + 标题 + 描述
- 利益 = 特性 + 用户获得的实际价值

**设计要点**：
- 与 Features 区分：Features 讲 "产品有什么"，Benefits 讲 "你得到什么"
- 使用情感化描述（"每天早晨醒来，皮肤像婴儿般柔软"）
- 图标风格统一，色彩协调

---

## 6. How It Works Section

**内容指南**：
- 标题："简单 3 步"
- 使用流程：开箱/下单 → 使用 → 享受结果
- 每步配 lifestyle 场景图

**设计要点**：
- 水平步骤条，移动端垂直
- 步骤图展示真实使用场景
- 强调 "简单" 和 "即时效果"

---

## 7. Testimonials Section

**内容指南**：
- 4-6 条用户评价
- 包含：头像、姓名、地点、使用时长、具体效果
- 优先展示带照片/视频的 UGC
- 成果要量化（"使用 2 周后，皮肤水分提升 40%"）

**设计要点**：
- 卡片网格或轮播（Carousel）
- 真实头像，避免 stock photo
- 星级评分可视化
- 可添加视频 testimonial（如有）

---

## 8. Guarantee Section

**内容指南**：
- 标题："零风险尝试"
- 保障内容：
  - 退款政策（"30 天无理由全额退款"）
  - 质保（"2 年免费保修"）
  - 配送（"全国包邮，48 小时发货"）
  - 客服（"7×24 小时在线支持"）
- 用徽章/图标可视化保障

**设计要点**：
- 使用信任色（绿色、蓝色）
- 大图标 + 简短文字
- 可添加信任印章（SSL、支付安全）
- 此 Section 后直接接 CTA

---

## 9. CTA Section

**内容指南**：
- 标题：紧迫感驱动（"限时优惠，库存有限"）
- 价格信息：原价 + 折扣价 + 节省金额
- CTA 按钮："立即购买 - 节省 ¥200"
- 紧迫感元素：倒计时、库存数量、限时标签
- 再次强调保障："不满意全额退款"

**设计要点**：
- 使用高对比背景（深色底 + 亮色按钮，或反之）
- 按钮最大、最突出
- 倒计时动态更新（如有）
- 支付方式图标（支付宝、微信、信用卡）
- 可添加 "加入购物车" 和 "立即购买" 双按钮

---

## 常见陷阱

1. **产品图质量低**：电商页面 70% 决策基于图片，必须使用高清 lifestyle 图
2. **忽视移动端**：60%+ 电商流量来自移动端，按钮要足够大
3. **缺少紧迫感**：没有 scarcity/urgency 元素，用户容易拖延
4. **保障信息隐藏**：退款政策要放在 CTA 附近，而非 Footer
5. **加载速度慢**：产品图需优化，首屏加载 < 3 秒
