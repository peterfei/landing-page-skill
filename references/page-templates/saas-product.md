# SaaS 产品页模板

## 适用场景

- B2B SaaS 工具
- 订阅制软件产品
- 开发者工具 / API 服务
- 协作/生产力工具

## Section 结构

```
Hero → Social Proof → Problem → Solution → Features → How It Works → Testimonials → Pricing → FAQ → Final CTA
```

---

## 1. Hero Section

**内容指南**：
- 标题：使用 hero-headlines.md 公式，强调具体结果（如 "3 倍提升销售线索"）
- 副标题：一句话解释产品是什么、为谁服务
- CTA：主按钮 "开始免费试用" + 次要按钮 "观看演示"
- 视觉：产品界面截图或 demo 视频预览

**设计要点**：
- 首屏必须包含 CTA，无需滚动即可看到
- 使用非对称布局（文字 60% + 产品图 40%）
- 背景使用 subtle 渐变或纯色，避免分散注意力

---

## 2. Social Proof Section

**内容指南**：
- 客户 Logo 墙（5-8 个 recognizable 品牌）
- 关键数据："已有 10,000+ 团队使用"、"4.9/5 评分"
- 一句话社会证明："被 [权威媒体] 评为 2024 最佳 [类别] 工具"

**设计要点**：
- Logo 使用灰度/单色处理，避免视觉杂乱
- 数据用大字号突出显示
- 紧邻 Hero 下方，建立即时信任

---

## 3. Problem Section

**内容指南**：
- 标题：点出目标用户的痛点（"还在用 Excel 手动跟踪客户？"）
- 3 个痛点列表，每个配简短描述
- 痛点要具体、可共鸣，避免泛泛而谈

**设计要点**：
- 使用暗色背景或对比色块，与前后 Section 区分
- 痛点用图标 + 标题 + 描述的三元组展示
- 营造 "我们理解你的痛苦" 的共情氛围

---

## 4. Solution Section

**内容指南**：
- 标题：产品如何解决上述痛点（"一站式自动化客户管理"）
- 核心价值主张：3 句话以内
- 产品截图或流程图

**设计要点**：
- 与 Problem Section 形成视觉对比（暗→亮或反之）
- 产品图要高质量、有真实数据填充
- 使用箭头或流程线引导视线

---

## 5. Features Section

**内容指南**：
- 标题："强大功能，简单易用"
- 3-4 个核心功能，每个配图标 + 标题 + 一句话描述
- 避免功能罗列，聚焦 "用户能做什么"

**设计要点**：
- 使用 3 列网格（移动端单列）
- 卡片式布局，hover 有微动效
- 第 2 个功能卡片可略微突出（推荐标签）

---

## 6. How It Works Section

**内容指南**：
- 标题："3 步开始使用"
- 3 步流程：注册 → 配置 → 见效
- 每步配序号 + 标题 + 一句话说明

**设计要点**：
- 水平时间线或垂直步骤条
- 步骤间用箭头/线条连接
- 最后一步展示结果（如 "看到数据增长"）

---

## 7. Testimonials Section

**内容指南**：
- 3-4 条用户评价
- 每条包含：真人头像、姓名、职位、公司、具体成果数据
- 避免匿名评价和泛泛夸赞

**设计要点**：
- 卡片式布局，引用符号装饰
- 头像真实、高质量
- 成果数据加粗突出

---

## 8. Pricing Section

**内容指南**：
- 标题："简单透明的定价"
- 3 档定价：Free / Pro / Enterprise
- 每档包含：价格、核心功能列表、CTA 按钮
- 推荐中间档（Pro），用视觉高亮

**设计要点**：
- 3 列对比表格（移动端可横向滑动或堆叠）
- 推荐档使用不同背景色或边框高亮
- 价格数字用大字号，周期用小字号
- 包含 "常见问题" 链接或月付/年付切换

**定价表结构**：

| 功能 | Free | Pro（推荐） | Enterprise |
|------|------|------------|------------|
| 价格 | ¥0 | ¥99/月 | 联系销售 |
| 用户数 | 1 人 | 10 人 | 无限 |
| 核心功能 A | ✅ | ✅ | ✅ |
| 核心功能 B | ❌ | ✅ | ✅ |
| 核心功能 C | ❌ | ❌ | ✅ |
| CTA | "免费开始" | "开始试用" | "联系销售" |

---

## 9. FAQ Section

**内容指南**：
- 5-7 个高频问题
- 覆盖：价格、安全、上手难度、数据迁移、退款政策
- 使用 objection-handling.md 的反论模板

**设计要点**：
- 手风琴折叠面板（Accordion）
- 问题用用户口吻，答案简洁
- 最后一个问题引导联系客服

---

## 10. Final CTA Section

**内容指南**：
- 标题：重申核心价值（"准备好提升效率了吗？"）
- 副标题：消除最后顾虑（"14 天免费试用，无需信用卡"）
- CTA 按钮：与 Hero 一致（"开始免费试用"）
- 可添加紧迫感元素："限时优惠，本月注册享 8 折"

**设计要点**：
- 使用 Primary 色背景或高对比背景
- 按钮最大、最突出
- 可添加输入框（邮箱）直接开始
- 底部添加信任徽章（安全认证、退款保障）

---

## 常见陷阱

1. **功能堆砌**：不要列出 10+ 个功能，聚焦 3-4 个核心
2. **定价模糊**：避免 "联系我们获取报价" 作为唯一选项
3. **缺少数据**：社会证明和 Testimonials 要有具体数字
4. **CTA 单一**：至少 3 个 CTA（Hero、中段、底部）
5. **忽视移动端**：SaaS 用户 40%+ 来自移动端浏览
